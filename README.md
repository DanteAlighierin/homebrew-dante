# Dante Art

## How do I install these formulae?

`brew install dante/art/<formula>`

Or `brew tap dante/art` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dante/art"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
